## DNのルール

- C: `JP` 固定
- ST / L: 機関ごとの固定値（届出済みの都道府県・市区町村のローマ字表記）。両方必須
- O: 機関名英語表記。半角英数64文字以内、記号は `'(),-./:=` と半角スペースのみ
- CN: 対象サーバのFQDN、64文字以内。半角英数と `.` `-` のみ、先頭末尾に `.` `-` 不可
- Email属性は使用不可
- CSR内のDN順序は C→ST→L→O→CN またはその逆順であること

## 聞き取り順の目安

1. CSR（貼り付けてもらう。DN・鍵種はCSRから抽出でき、項目1・2・11の確認が楽になる）
2. CSRから抽出したDN・プロファイルIDをユーザーに確認
3. 利用管理者の氏名・所属・メール
4. ソフトウェア名・バージョン
5. 複数ホスト名（SANs）の要否 → 必要ならdNSName

CSRをまだ作っていない場合は、先にサーバ上でのCSR作成を案内する（RSA 2048bitまたはECDSA secp384r1。openssl例の提示可）。
