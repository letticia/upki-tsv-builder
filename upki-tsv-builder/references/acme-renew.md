# ACME利用情報 更新申請TSV（5-5-2）

種別ID: `acme-renew` / 全13列 / 1ファイル最大99件

既存ACMEアカウントの登録内容（dNSNameの追加・変更、プロファイル変更など）を更新する申請。**通常の証明書の自動更新にはこの申請は不要**（ACMEクライアントが行う）。ユーザーが「ACMEの更新」と言った場合は、登録情報の変更が目的かを必ず確認する。

## 項目仕様

acme-create.md と同じルール。違いは**項目3に更新対象のACMEアカウントIDが入る**ことのみ。

## 聞き取り時の補足

- ACMEアカウントIDは、ACME利用開始時の通知やACMEクライアントの設定（例: legoの `accounts` ディレクトリ、certbotの `/etc/letsencrypt/accounts` 相当の登録情報）で確認できると案内する。不明な場合は登録担当者へ。
