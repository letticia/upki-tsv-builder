# upki-tsv-builder

UPKI電子証明書発行サービス（国立情報学研究所）の申請TSVファイルを、利用管理者との**対話形式**で作成するための [Agent Skill](https://agentskills.io/) です。なるべく簡単に、Claudeなどとの対話を通じて正しい形式のTSVファイルを作成できることを目指しています。

## 特徴

- サーバ証明書の **発行・更新・失効** 申請、ACME利用情報の **作成・更新・停止・証明書失効** 申請に対応
- サーバのURL/FQDNから現在の証明書情報（DN・シリアル番号・SAN・鍵種・有効期限）を取得し、**更新申請やACME移行申請のTSVを事前入力**
- ACMEへの移行を案内しつつ、従来方式での更新も選べる（選択は利用者に委ねる方針）
- 出力ファイルは Shift-JIS / CR+LF / 列数固定のタブ埋めをスクリプトが機械的に保証
- CSRの解析（鍵種・鍵長・DN順序・主体者DNとの一致）、失効理由コードの誤選択防止などの検証を内蔵

## 対応する申請種別

| 種別         | 手続き                                |
| ------------ | ------------------------------------- |
| サーバ証明書 | 発行 / 更新 / 失効                    |
| ACME利用情報 | 作成 / 更新 / 停止 / 発行証明書の失効 |

## 動作要件

- **コード実行とファイル作成（Code execution and file creation）が有効な実行環境**
- **Python 3** と **cryptography** ライブラリ（CSR・証明書の解析に使用）
- 各申請項目の仕様は `references/` 配下のMarkdownにまとめてあり、Claude はこれを参照して対話します

## インストール

### Claude.ai（Web / デスクトップ / モバイル）

1. 設定で **コード実行とファイル作成** を有効にする
2. このリポジトリの `upki-tsv-builder/` フォルダだけをZIP圧縮する
   （リポジトリ全体ではなくスキル本体フォルダを固めること。ZIP解凍時に `upki-tsv-builder/SKILL.md` が直下に来る構造にする）
   - もしくは [Releases](../../releases) から完成済みの `.skill` ファイルをダウンロードする（こちらが簡単です）
3. 「カスタマイズ > スキル」を開き、「+」→「スキルを作成」からZIP（または `.skill`）をアップロードする
4. スキル一覧に表示されたらオンにする

> macOSでZIPを作る場合は `zip -rX upki-tsv-builder.zip upki-tsv-builder -x '*.DS_Store'` とすると不要なメタファイルが入りません。

### Claude Code

スキルフォルダを配置するだけです（アップロード不要）。

```bash
# 個人用
cp -r upki-tsv-builder ~/.claude/skills/
# またはプロジェクト用
cp -r upki-tsv-builder <your-project>/.claude/skills/
```

### その他のツール

Agent Skills はオープンスタンダードのため、対応するツール（VS Code、Cursor、goose など）でも利用できます。各ツールのドキュメントに従ってスキルフォルダを配置してください。

## 使い方の例

スキルを有効にした状態で、たとえば次のように話しかけます。

- 「www.example.ac.jp のサーバ証明書を更新したい」
- 「このサーバを ACME に移行したいので申請ファイルを作って」
- 「サーバ証明書の発行申請TSVを作りたい」

Claude が申請種別を判断し、必要な項目を順に聞きながらTSVファイルを生成します。FQDNを伝えると現在の証明書情報を取得し、更新・移行のどちらで進めるかを提案します。

## ⚠️ 注意

- このスキルが生成したTSVファイルは、**各機関の手続きに従い、登録担当者へ提出する前に必ず内容を確認してください**。生成物の正確性を保証するものではありません。
- 仕様や運用は変更される可能性があります。最新の正式な仕様は [UPKIの公式マニュアル](https://nii-auth.atlassian.net/wiki/spaces/UPKIManual/overview?homepageId=43876354) を参照してください。
- スキルに **秘密鍵を入力しないでください**。証明書の申請にはCSR（公開鍵を含む申請データ）のみを使用します。

## リポジトリ構成

```
upki-tsv-builder/          スキル本体（この階層ごとZIP化する）
├── SKILL.md               対話フローと全体ワークフロー
├── references/            申請種別ごとの項目仕様
└── scripts/               TSV生成・検証、証明書情報取得スクリプト
examples/                  サンプル入力・出力（任意）
```
